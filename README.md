# AweReader
Awesome E-reader application made using Qt6 and MuPDF

# Features
- Supports pdf / epub files

# Usage
To read a document, just run:
```bash
./reader <document path>
```
Where `<document path>` is the path of the file you want to read

To zoom in/out of the page, use the scrollwhell. Holding left-click on the mouse and moving the cursor will move the pdf-page

To change what page you are at, use the bottom buttons for going to the previous/next page

# Depedencies
- [CMake](https://cmake.org) (used for compiling)
- [MuPDF](https://mupdf.com/)
- [Qt 6](https://doc.qt.io/qt-6/)

# How to compile:
there are two ways of compiling from source:
- compiling manualy
- using `make.sh`

To compile manualy, you can just run:
```bash
cmake -B build && cmake --build build 
```
and then the executable will be located at the `build` directory.

To only compile with `make.sh` you run it and passing `build` as a argument:
```bash
./make.sh build
```

## The make.sh script
make.sh is a shell script for doing things just by running a single command. For example, to build and run 
```bash
./make.sh <document path>
```

> [!NOTE]
> You can run shell scritps without giving it permition by adding `bash` (or your prefered shell) to the start of the command
>```bash
>bash make.sh <args>
>```

### Commands:
- **Building and running the app:**
```bash
./make.sh <document path>
```
Where `<document path>` is the path of the document you want to read

- **Only build the app:**
```bash
./make.sh build
```

- **Only run the app:**
> [!NOTE]
> You need to have a compiled executable in `build/` for this one to work
```bash
./make.sh run <document path>
```
Where `<document path>` is the path of the document you want to read

- **Remove files generated by CMake:**
> [!NOTE]
> You can change what files get deleted by changing the clean() function in the script
```bash
./make.sh clean
```
or 
```bash
./make.sh clear
```

- **Generate `compile_commands.json`:**
```bash
./make.sh cc
```
